**The client is installable on a phone, so every screen the engine serves has to work on
one.** Below a 640px breakpoint each one draws a phone layout, and the engine pushes a
notification when a trak parks at a gate, finishes, fails or gives up waiting on a
condition — so a trak can be answered from a locked screen rather than only from a desk.
One thing the rule does not reach: the desktop shell's launch window, which nothing but
`Orkestra.app` can show. The project rail is reached — a host serves it at its root. `client-style` has the seam, the touch floor, the safe-area
tokens and the one test tier that can see any of them.
