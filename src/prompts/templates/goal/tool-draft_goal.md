Draft the goal file for a goal the person asked for in a sentence. `name` is lowercase-kebab
and not held by another goal in this project. `title` is short; `line` is the one sentence
a list shows; `finished` is what is true once the goal is over, specific enough to check,
opening with the scope you assumed and what you left out. `parallel`, `traks_per_hour` and
`traks_per_day` are optional limits; leave out any the work does not need. `branch` is an
optional goal branch every trak lands on instead of the default branch, reaching it as one
pull request once the goal is done: propose one where the work should arrive whole, or
where this project's rules for goals say to. The run modes are filled in for you. The
person sees the draft when your turn ends and approves it or asks for changes.
