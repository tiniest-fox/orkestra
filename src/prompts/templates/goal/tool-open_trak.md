Open one trak of the goal: `title` is what a list shows, `description` the request the
trak starts from, `mode` how much of it the person stands at. `auto_merge: true` has
Orkestra merge its pull request once it merges cleanly and its checks pass; leave it out
for one the person merges. A goal set to merge every trak opens each with it whatever you
pass, and one set to merge none refuses it. Refused, with the reason, while the goal is
paused or past any of its limits. Answers with the new trak's id.
