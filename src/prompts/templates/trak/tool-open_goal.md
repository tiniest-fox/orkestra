Open a goal from `asked`, a sentence saying what the goal is for. Call it only when the
person asks for a goal — work that outlasts one trak and is planned as several — never
for work this chat could plan itself.

The goal's composer starts drafting its file at once, and the person approves it on the
goal's own screen before any trak is opened. The goal runs its traks on this trak's run
mode and records that this trak opened it. Answers with the goal's id.
