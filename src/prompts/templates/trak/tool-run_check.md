Run one of this project's checks, as the engine runs it after a step's turn, and answer
with its verdict and what it printed. `name` is one of the checks listed for it: every
check that keeps a pass, whether or not it runs after this step.

A pass is kept against the files as they stand, so the engine does not run that check
again after you finish unless a file changes. A check marked to run alone waits for any
other to finish first. Leave the files alone while it runs: a pass the files moved under
is not kept.
